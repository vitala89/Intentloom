# Archived implementation plans

These files are retained for historical context. They are not current roadmap
authority.

They are the working plans for Engineering Quality Packs phases Q3–Q14. They
previously lived at the repository root as `implementation_plan.md` and
`implementation_plan_q4.md` through `implementation_plan_q14.md`. Git history
preserves those paths. Historical Duty Watch entries still name the old root
paths; those entries are chronological records, not live links.

Absolute `file://` links inside some plans are historical local paths from the
machine that drafted them. They were not rewritten.
