# Icon glyph attribution

`glyphs.ts` is generated from [Lucide](https://lucide.dev), used under the ISC
licence. It contains the drawing elements of the glyphs listed in
`scripts/desktop/generate-design-icons.mjs`, extracted from the `lucide-static`
package at author time and committed so the application fetches nothing at
runtime.

Regenerate with:

```sh
node scripts/desktop/generate-design-icons.mjs
```
